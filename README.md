# Alex Di Falco DJ — sito booking

Sito statico orientato alla conversione per DJ set a Roma, locali, aperitivi ed eventi privati.

## Stato attuale

- Homepage commerciale con call to action booking
- Landing SEO: DJ set Roma, eventi privati, locali/aperitivi
- Pagina contatti con Instagram attivo e spazio WhatsApp booking
- Metadati SEO e Open Graph
- Dati strutturati Schema.org `ProfessionalService` / `Service`
- `robots.txt`, `sitemap.xml`, manifest e favicon
- Deploy automatico su GitHub Pages via Actions

## URL provvisorio

Dopo l'attivazione di GitHub Pages il sito sarà disponibile su:

`https://alessandrocdifalco.github.io/sito-alex-di-falco/`

Quando verrà acquistato un dominio personale, dovranno essere aggiornati canonical, sitemap, Open Graph URL e dati strutturati.

## Informazioni da inserire prima del lancio commerciale

1. Numero WhatsApp Business o email pubblica di booking.
2. Scelta definitiva del brand: `Alex Di Falco DJ` oppure progetto condiviso per eventi.
3. Foto reali di qualità o visual ufficiali per hero e condivisione social.
4. Servizi tecnici effettivamente offerti: impianto audio, luci, durata set, trasferta.
5. Recensioni reali e venue/eventi già svolti, solo se pubblicabili.

## SEO locale: attività necessarie fuori dal codice

- Collegare dominio personale breve e coerente con il brand.
- Creare o ottimizzare Google Business Profile, se il servizio e l'indirizzo/area servita rispettano i requisiti Google.
- Registrare il sito su Google Search Console e inviare `sitemap.xml`.
- Pubblicare pagine/contenuti reali su servizi, quartieri e tipologie di evento servite, evitando pagine duplicate costruite solo per keyword.
- Ottenere link e citazioni autentiche da locali, eventi, social e profili musicali.
- Misurare contatti reali tramite link WhatsApp con evento analytics, quando sarà deciso il sistema di tracking.
